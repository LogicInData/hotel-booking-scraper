# Hotel Booking Scraper

This project is a Python-based web scraper designed to extract hotel details from Booking.com. It allows users to scrape information such as hotel names, locations, prices, ratings, reviews, and more, based on the location and date range selected. The data is then saved into a CSV file for easy access and further analysis.

## Features
- Scrapes hotel data from Booking.com based on user-defined location and dates.
- Extracts key details including:
  - Hotel Name
  - Location
  - Price per Night
  - Rating and Score
  - Number of Reviews
  - Link to Hotel Page
- Data is saved in a CSV format for easy export and analysis.
